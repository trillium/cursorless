# Command demo

A preview of what a Cursorless command actually does: the spoken command
comes in, the target lights up, and the edit lands.

## "chuck vest"

Removes the token under the `v` hat.

<img
  src="/img/commands/chuck-vest.svg"
  alt="Animated demo of the 'chuck vest' Cursorless command"
/>

## "call vest"

Wraps the token under the `v` hat in a function call.
